# Smisha legacy palette backup

Captured before the site-wide visual refresh on 4 November 2026.

The legacy theme was a blue-and-sky-blue system, with its primary values set in
`styles.css` as:

| Token | Legacy value |
| --- | --- |
| Primary / `--green` | `#0C2D73` |
| Highlight / `--lime` | `#4BC8FF` |
| Ink / `--ink` | `#10275B` |
| Card surface / `--card` | `rgba(255, 255, 255, .88)` |
| Page background | `#182B3E` |

The original styles remain recoverable from Git history. This record preserves
the previous palette's canonical starting tokens before the teal-and-gold
rebrand.
